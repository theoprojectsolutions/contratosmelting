Administração

Base de dados do motor

Importe as exportações do SIG. O cadastro alimenta as respostas; o histórico de vendas alimenta o consumo real e os KPIs.

Cadastro de produtos

Exportação "cad_produtos" do SIG (pode mandar todos os arquivos de origem juntos). Substitui/atualiza pelo código do produto.

Histórico de vendas

Exportação "relsitped" do SIG (pedido, cliente, produto, código do cliente, quantidade, preço, data). Pode reimportar: não duplica.

Histórico de cortes (correias planas e Mectrol)

Exportações "relpro_nita" e "relpro_mec" do SIG (pode mandar as duas juntas). O motor usa para responder correias planas (material pelo código → base + "cortar L × C"; outra marca → materiais já cortados na mesma medida) e correias sincronizadoras sem pronta no cadastro (LL Mectrol → rolo + "cortar e emendar").

Kits SGM (produtos montados)

Exportação "relpro_sgm" do SIG: cada SGM com a peça principal, os componentes e a mão de obra. Os kits que ainda não estão no cadastro entram no motor; pedido com "SGM 7336" volta direto com o ID do kit.

Ensinar com planilhas já respondidas

Suba contratos que a Melting já respondeu (com o código do cliente e o ID Melting). Vira de-para: na próxima planilha desse cliente, esses códigos voltam com o ID certo, e os padrões ajudam em itens parecidos.

Planilhas

Envie as planilhas de contratos geradas no Excel — ficam organizadas aqui em ordem alfabética.

Importar planilha oficial (Contratos + Cotações)

Envie a planilha de controle da Melting (abas "Controle_Contratos", "Controle_Cotações_2025" e "Controle_Cotações_2026") — o sistema lê e cadastra tudo automaticamente, já aparecendo no Dashboard.

Ver o formato exato que a planilha precisa ter

O arquivo precisa ter pelo menos uma dessas abas, com esse nome exato:

Aba "Controle_Contratos" — colunas: N°, Cliente, Vendedor, Período, Segmento, Data inicial, Data do vencimento, Status, Data reajuste, Situação, Observação.

Abas "Controle_Cotações_2025" / "Controle_Cotações_2026" — colunas: N°, Cliente, Internos, Externos, Tipo (só 2026), Segmento, Data recebimento, Data retorno, Total de itens (estimado), Total de itens (cotados), %, R$ cotados total, Total de itens (vencidos), R$ total estimado (vencidos), Observação, Data última atualização.

O sistema reconhece as colunas pelo nome do cabeçalho, não pela posição — então pode reordenar ou adicionar colunas extras que não atrapalha. Só o nome das abas precisa ser exatamente esse.
